

# BizManager

**Live Demo:** [Open BizManager](https://bizmanager-hz58.onrender.com)

A simple inventory management web application built with Python, Flask, and SQLite.

## Features

- Add new products
- Edit existing products
- Delete products
- Search products
- View inventory statistics
- Calculate total stock value
- Identify products with low stock

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git and GitHub

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/giwrgospanagos/BizManager.git
   ```

2. Navigate to the project directory:

   ```bash
   cd BizManager
   ```

3. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

4. Activate the virtual environment on Windows:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

5. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Run the application:

   ```bash
   python app.py
   ```

7. Open your browser at:

   http://127.0.0.1:5000

## Purpose

This project was created as a practical learning project to develop skills in Python, web development, database management, and version control.
